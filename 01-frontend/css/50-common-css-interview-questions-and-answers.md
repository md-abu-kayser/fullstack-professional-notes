# Common CSS Interview Questions and Answers

Frequent interview topics include: explaining specificity and the cascade, the difference between content-box and border-box, how flexbox and grid differ, what causes margin collapsing, and how to center a div (several valid answers, flexbox being the most common today).

```css
/* "Center a div" - the flexbox answer */
.parent { display: flex; justify-content: center; align-items: center; }
```

**Key takeaway:** Interviewers often follow up "how would you center a div" by asking for two or three different methods - know flexbox, grid, and absolute positioning with transform.
