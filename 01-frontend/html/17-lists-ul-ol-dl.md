# Lists: ul, ol, dl

ul creates an unordered (bulleted) list, ol an ordered (numbered) list, and dl a description list pairing terms (dt) with descriptions (dd). Lists give assistive technology a count and structure - screen readers announce something like "list, 3 items."

```html
<dl>
  <dt>HTML</dt>
  <dd>Structures web content</dd>
</dl>
```

**Key takeaway:** Nesting a ul inside an li is valid and common for multi-level navigation menus.
