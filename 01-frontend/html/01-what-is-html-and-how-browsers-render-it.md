# What is HTML and How Browsers Render It

HTML (HyperText Markup Language) is the standard markup language for structuring content on the web. It describes the meaning and structure of a page using elements like headings, paragraphs, links, and images. Browsers parse HTML into a tree structure called the DOM (Document Object Model), then combine it with CSS (visual styling) and JavaScript (behavior) to render the final page. HTML itself carries no styling or logic - it is purely structural.

```html
<!DOCTYPE html>
<html>
  <head><title>My Page</title></head>
  <body><h1>Hello, World!</h1></body>
</html>
```

**Key takeaway:** HTML defines structure and meaning, not appearance - that is CSS's job.
