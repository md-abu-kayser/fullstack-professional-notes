# HTML5 Document Structure and Boilerplate

Every HTML5 document follows a standard skeleton: a DOCTYPE declaration, an html root element, a head for metadata, and a body for visible content. Getting this boilerplate right ensures consistent rendering across browsers and gives search engines and screen readers the metadata they need.

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>

</body>
</html>
```

**Key takeaway:** Always set lang and viewport - they affect accessibility and mobile rendering immediately.
