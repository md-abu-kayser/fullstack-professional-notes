# Semantic HTML Overview

Semantic HTML means choosing elements that describe their meaning, not just their appearance - using a real button instead of a styled div for a clickable action, for example. Semantic markup improves accessibility for screen readers, gives search engines clearer signals for SEO, and makes code more self-documenting for other developers.

```html
<article>
  <h2>Blog Post Title</h2>
  <p>Content goes here...</p>
</article>
```

**Key takeaway:** If a non-semantic div can be replaced by a semantic tag, it usually should be.
