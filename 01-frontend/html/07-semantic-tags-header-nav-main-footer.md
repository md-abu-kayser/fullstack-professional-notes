# Semantic Tags: header, nav, main, footer

These landmark elements divide a page into recognizable regions. header typically holds branding and top navigation, nav wraps primary navigation links, main contains the unique content of the page (used only once), and footer holds closing content like copyright or contact links.

```html
<header>...</header>
<nav>...</nav>
<main>...</main>
<footer>...</footer>
```

**Key takeaway:** Screen readers can jump directly between these landmarks, which is a major accessibility win.
