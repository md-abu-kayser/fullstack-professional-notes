# HTML Tags vs Elements vs Attributes

These three terms are often used interchangeably but mean different things. A tag is the markup itself, like an opening or closing bracket pair. An element is the tag plus its content, like a full paragraph with its text. An attribute provides extra information about an element, written inside the opening tag.

```html
<a href="https://example.com" target="_blank">Visit</a>
```

**Key takeaway:** href and target here are attributes; the whole anchor together forms the element.
