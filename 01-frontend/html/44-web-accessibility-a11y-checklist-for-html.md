# Web Accessibility (a11y) Checklist for HTML

A practical baseline checklist: semantic landmarks used correctly, all images have appropriate alt text, form inputs have associated labels, color is never the only way information is conveyed, heading levels are not skipped, and every interactive element is keyboard-focusable with a visible focus state.
