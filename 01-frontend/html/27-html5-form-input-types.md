# HTML5 Form Input Types

HTML5 added specialized input types beyond text and password: email (validates format), date, time, range (a slider), color (a color picker), number, tel, and url. Mobile browsers also adapt their on-screen keyboard based on the type.

```html
<input type="date">
<input type="range" min="0" max="100">
<input type="color">
```

**Key takeaway:** These types trigger the right mobile keyboard automatically - a free UX win with zero JavaScript.
