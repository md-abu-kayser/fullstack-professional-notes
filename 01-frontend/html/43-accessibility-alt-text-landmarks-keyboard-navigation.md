# Accessibility: alt Text, Landmarks, Keyboard Navigation

Solid HTML accessibility rests on three pillars: meaningful alt text on images, semantic landmark elements so assistive tech users can jump around the page, and full keyboard operability, since every interactive element must be reachable and usable without a mouse.

```html
<img src="logo.png" alt="Acme Inc. logo">
```

**Key takeaway:** Try navigating your own page using only Tab and Enter - it reveals accessibility gaps instantly.
