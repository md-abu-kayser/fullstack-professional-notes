# Meta Tags for SEO and Social Sharing

The meta tag inside head carries page metadata invisible to visitors but critical to browsers, search engines, and social platforms. A description meta tag summarizes the page for search results, while a robots meta tag controls indexing behavior.

```html
<meta name="description" content="Learn full-stack web development from scratch.">
<meta name="robots" content="index, follow">
```

**Key takeaway:** A missing or duplicate description tag is one of the most common on-page SEO mistakes.
