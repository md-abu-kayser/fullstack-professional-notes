# HTML Validation and Why It Matters

Validating HTML against the W3C standard catches unclosed tags, invalid nesting, and duplicate IDs before they cause inconsistent rendering across browsers. Invalid HTML often still "works" visually but can silently break accessibility tools and older parsers.

```html
<!-- Check any page with the official W3C markup validator -->
```

**Key takeaway:** Browsers are forgiving of invalid HTML, but screen readers and search engine crawlers often are not.
