# Deployment to Vercel

Vercel, the company behind Next.js, offers the most seamless deployment path - connecting a GitHub repository triggers automatic builds and preview deployments per pull request, with edge network distribution and zero server configuration for most use cases.

```bash
npm i -g vercel
vercel
```

**Key takeaway:** Preview deployments per pull request are one of Vercel's most valuable features for teams - every PR gets its own live, shareable URL automatically before merging.
