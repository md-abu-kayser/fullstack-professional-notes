# What is Next.js and Why Use It

Next.js is a React framework that adds production-grade features React alone does not include: file-based routing, server-side rendering, static generation, built-in API routes, image and font optimization, and a clear project structure. It removes most of the configuration burden of hand-rolling a React setup with a bundler, router, and SSR pipeline.

```bash
npx create-next-app@latest my-app
```

**Key takeaway:** Choose Next.js over plain React whenever SEO, initial load performance, or a full-stack setup (frontend plus API) matters - a client-only SPA is fine when none of those apply.
